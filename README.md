CCSA105 – Policy Layers

About This Assignment

This repository contains my CCSA105 practical assignment on Policy Layers in Check Point Security Management.

The assignment focuses on understanding how policy layers work, how rules are arranged and evaluated, and how Ordered Layers and Inline Layers help control network traffic.


Topics Covered

Reviewing the default Access Control policy.

Understanding the default Ordered Layer and Cleanup Rule.

Creating and arranging Ordered Layers.

Configuring firewall rules and service restrictions.

Understanding Inline Layers and how they are used within a parent rule.

Installing policies and testing network traffic.

Understanding the effect of changing the order of policy layers.

Reviewing policy sharing and its purpose.


Practical Work and Environment Limitations

I used the SmartConsole environment provided through my training programme.

Some practical activities could not be completed because my school account had restricted permissions. For example, creating a new Policy Package, creating additional layers, publishing changes and installing the policy were not available to my account.

I was able to inspect the available policy environment and work through the assignment requirements. Where practical tests could not be performed, the expected results are explained as part of my analysis. They are not presented as actual test results.
